## Uso offline

A aplicação pode ser servida por HTTP ou HTTPS (por exemplo, em `http://localhost` ou por um servidor HTTPS); abrir o arquivo `index.html` diretamente não permite registrar o service worker. Pesquisa na web, páginas abertas em iframes e conteúdo remoto continuam dependendo de internet. Arquivos e imagens externos só ficam disponíveis offline depois de serem carregados e armazenados pelo navegador.
